Edupage Extras Privacy Policy

Last updated November 19, 2026.

Usage analytics

Edupage Extras uses a self-hosted Umami server at analytics.kryptosss.xyz to measure extension usage. When analytics are enabled, the extension sends an HTTPS request with a fixed extension identifier and a generic pageview when an EduPage page loads. It also sends an event when Stay Active Mode is enabled or disabled or when its test page is opened.

The server receives the request IP address and browser user agent. Analytics requests omit cookies, credentials, referrers, actual EduPage URLs, school names, page content, and account details.

You can stop future analytics requests in Settings → Privacy → Usage analytics. On Chromium browsers, analytics are enabled by default. On Firefox, the extension also requires the optional Technical and interaction data permission before sending analytics.

Data processed in your browser

The extension reads data already available in EduPage to display grades, attendance, timetables, and other enhancements. Settings and attendance and timetable caches are stored locally. Timetable exports are generated locally. The extension does not collect EduPage login credentials.

If you enable test saving and save a test, the browser profile stores the question text, recorded answers, readable question images, school origin, and capture timestamps. You can delete saved tests from the extension. Diagnostics are generated locally and can be exported or shared by you.

Optional external requests

  • Update checks. When enabled, the extension requests public version information from GitHub. GitHub receives ordinary network request metadata.
  • Test Question Helper. When you explicitly request help, the extension sends the current question and any choices already selected to the AI provider you configured. If you enabled reference notes for AI requests, those notes can also be included. Provider credentials are stored in the browser and used to authenticate to the selected provider. The cloud providers are OpenAI, Google Gemini, NVIDIA, and OpenRouter. Their own privacy and retention policies apply to requests they receive. Ollama and LM Studio use a local endpoint on your device.

Questions and data requests

For privacy questions or requests about analytics data, contact the maintainers through the Edupage Extras issue tracker. Please keep personal information out of public issues.

Zásady ochrany súkromia Edupage Extras

Posledná aktualizácia 19. novembra 2026.

Analytika používania

Edupage Extras meria používanie rozšírenia pomocou vlastného servera Umami na adrese analytics.kryptosss.xyz. Pri zapnutej analytike rozšírenie pri načítaní stránky EduPage odošle požiadavku cez HTTPS s pevným identifikátorom rozšírenia a všeobecným záznamom o zobrazení stránky. Udalosť odošle aj pri zapnutí alebo vypnutí režimu Stay Active alebo pri otvorení jeho testovacej stránky.

Server dostane IP adresu požiadavky a identifikáciu prehliadača (user agent). Analytické požiadavky neobsahujú súbory cookie, prihlasovacie údaje, odkazujúcu adresu, skutočné adresy stránok EduPage, názvy škôl, obsah stránok ani údaje o účte.

Ďalšie odosielanie môžete vypnúť v časti Nastavenia → Súkromie → Analytika používania. V prehliadačoch založených na Chromiu je analytika predvolene zapnutá. Vo Firefoxe rozšírenie pred odosielaním vyžaduje aj voliteľné povolenie na zber technických údajov a údajov o interakciách.

Údaje spracúvané v prehliadači

Rozšírenie číta údaje dostupné v EduPage na zobrazenie známok, dochádzky, rozvrhu a ďalších vylepšení. Nastavenia a vyrovnávacie pamäte dochádzky a rozvrhu sa ukladajú lokálne. Exporty rozvrhu sa vytvárajú lokálne. Rozšírenie nezbiera prihlasovacie údaje do EduPage.

Ak zapnete ukladanie testov a uložíte test, profil prehliadača uchová text otázok, zaznamenané odpovede, čitateľné obrázky otázok, adresu školského webu a časy uloženia. Uložené testy môžete z rozšírenia vymazať. Diagnostické údaje sa vytvárajú lokálne a môžete ich exportovať alebo zdieľať.

Voliteľné externé požiadavky

  • Kontrola aktualizácií. Ak je zapnutá, rozšírenie si z GitHubu vyžiada verejné informácie o verzii. GitHub dostane bežné metadáta sieťovej požiadavky.
  • Pomocník s otázkami v teste. Keď výslovne požiadate o pomoc, rozšírenie odošle aktuálnu otázku a už vybrané možnosti nakonfigurovanému poskytovateľovi AI. Ak ste povolili pridávanie referenčného textu k požiadavkám AI, môže sa odoslať aj tento text. Prihlasovacie údaje poskytovateľa sa ukladajú v prehliadači a používajú sa na overenie u vybraného poskytovateľa. Cloudoví poskytovatelia sú OpenAI, Google Gemini, NVIDIA a OpenRouter. Na prijaté požiadavky sa vzťahujú ich vlastné pravidlá ochrany súkromia a uchovávania údajov. Ollama a LM Studio používajú lokálne rozhranie vo vašom zariadení.

Otázky a žiadosti týkajúce sa údajov

S otázkami o súkromí alebo žiadosťami týkajúcimi sa analytických údajov sa obráťte na správcov cez GitHub projektu Edupage Extras. Vo verejných hláseniach neuvádzajte osobné údaje.

Zásady ochrany soukromí Edupage Extras

Poslední aktualizace 19. listopadu 2026.

Analytika používání

Edupage Extras měří používání rozšíření pomocí vlastního serveru Umami na adrese analytics.kryptosss.xyz. Při zapnuté analytice rozšíření při načtení stránky EduPage odešle požadavek přes HTTPS s pevným identifikátorem rozšíření a obecným záznamem o zobrazení stránky. Událost odešle také při zapnutí nebo vypnutí režimu Stay Active nebo při otevření jeho testovací stránky.

Server obdrží IP adresu požadavku a identifikaci prohlížeče (user agent). Analytické požadavky neobsahují soubory cookie, přihlašovací údaje, odkazující adresu, skutečné adresy stránek EduPage, názvy škol, obsah stránek ani údaje o účtu.

Další odesílání můžete vypnout v části Nastavení → Soukromí → Analytika používání. V prohlížečích založených na Chromiu je analytika ve výchozím nastavení zapnutá. Ve Firefoxu rozšíření před odesíláním vyžaduje také volitelné oprávnění ke sběru technických údajů a údajů o interakcích.

Údaje zpracovávané v prohlížeči

Rozšíření čte údaje dostupné v EduPage pro zobrazení známek, docházky, rozvrhu a dalších vylepšení. Nastavení a mezipaměti docházky a rozvrhu se ukládají místně. Exporty rozvrhu se vytvářejí místně. Rozšíření neshromažďuje přihlašovací údaje do EduPage.

Pokud zapnete ukládání testů a uložíte test, profil prohlížeče uchová text otázek, zaznamenané odpovědi, čitelné obrázky otázek, adresu školního webu a časy uložení. Uložené testy můžete z rozšíření smazat. Diagnostické údaje se vytvářejí místně a můžete je exportovat nebo sdílet.

Volitelné externí požadavky

  • Kontrola aktualizací. Je-li zapnutá, rozšíření si z GitHubu vyžádá veřejné informace o verzi. GitHub obdrží běžná metadata síťového požadavku.
  • Pomocník s otázkami v testu. Když výslovně požádáte o pomoc, rozšíření odešle aktuální otázku a již vybrané možnosti nakonfigurovanému poskytovateli AI. Pokud jste povolili přidávání referenčního textu k požadavkům AI, může se odeslat i tento text. Přihlašovací údaje poskytovatele se ukládají v prohlížeči a používají se k ověření u vybraného poskytovatele. Cloudoví poskytovatelé jsou OpenAI, Google Gemini, NVIDIA a OpenRouter. Na přijaté požadavky se vztahují jejich vlastní pravidla ochrany soukromí a uchovávání údajů. Ollama a LM Studio používají místní rozhraní ve vašem zařízení.

Otázky a žádosti týkající se údajů

S otázkami o soukromí nebo žádostmi týkajícími se analytických údajů se obraťte na správce přes GitHub projektu Edupage Extras. Ve veřejných hlášeních neuvádějte osobní údaje.
